Fundamentação

Arquitetura do Problema

Sequências puras exigem 2 bits por nucleotídeo de forma contínua. Modelar a fita de DNA em blocos biológicos permite explorar redundâncias estruturais e minimizar o custo de persistência.

Integração E-utilities

Consumo direto da base científica NCBI. O motor extrai amostras FASTA brutas, garantindo que o algoritmo lide com assinaturas genômicas reais em tempo de execução.

Fragmentação por K-mers

O vetor linear é transformado em matrizes de k-mers de dimensão 3. Esse mapeamento imita a tradução ribossômica e isola as frequências de cada trinca.

Heurística de Huffman

Geração de árvore binária bottom-up por intermédio de fila de prioridades (Min-Heap). As trincas com maior taxa de repetição recebem roteamentos binários mais curtos.

Métricas de Eficiência

Validação quantitativa da compressão. O custo do vocabulário gerado dinamicamente é contrastado com a modelagem de hardware estática de 2 bits por canal.

Processamento

Pipeline de Transformação

Etapas lógicas empregadas para desconstruir o vetor de dados e reagrupá-lo de forma eficiente.

01

Aquisição de Matéria-Prima

O endpoint REST do NCBI retorna um bloco textual padrão FASTA. O cabeçalho de identificação é suprimido e a quebra de linhas normalizada, restando um vetor unidimensional de caracteres.

02

Construção do Histograma

O algoritmo executa uma varredura sequencial alocando blocos de 3 caracteres. Uma tabela hash registra a cardinalidade de cada códon distinto observado.

03

Ordenação via Min-Heap

Cada entrada do histograma é convertida em um nó isolado e inserida em um heap binário focado na frequência. O enraizamento respeita a complexidade O(log N) por inserção.

04

Mesclagem ambiciosa

A iteração consome perpetuamente os dois nós de menor massa, gerando um super-nó agregador que retorna ao heap. A convergência final produz a raiz única da codificação de Huffman.

05

Varredura de Roteamento

Uma navegação DFS pela árvore final estipula o prefixo binário de cada folha. Movimentos à esquerda anexam o bit 0, enquanto derivações à direita anexam o bit 1.

class No:
    def __init__(self, char, freq):
        self.char = char
        self.freq = freq
        self.esq = None
        self.dir = None

    def __lt__(self, other):
        return self.freq < other.freq

def Huffman(text):
    freq = {}
    for letra in text:
        freq[letra] = freq.get(letra, 0) + 1

    heap = []
    for caractere, frequencia in freq.items():
        push_heap(heap, No(caractere, frequencia))

    while len(heap) > 1:
        esq = pop_heap(heap)
        dir = pop_heap(heap)

        juntar_no = No(None, esq.freq + dir.freq)
        juntar_no.esq = esq
        juntar_no.dir = dir

        push_heap(heap, juntar_no)

    return heap[0]
src/ncbi_api.py Python 
import requests

def get_dna_sequence(accession):
    url = "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi"
    params = {
        "db": "nuccore",
        "id": accession,
        "rettype": "fasta",
        "retmode": "text"
    }
    
    try:
        response = requests.get(url, params=params)
        response.raise_for_status()
        
        lines = response.text.strip().split('\n')
        sequence = "".join(line.strip() for line in lines if not line.startswith('>'))
        
        return sequence
    except Exception as e:
        return None
src/main.py Python 
from ncbi_api import get_dna_sequence
from huffman import Huffman, gerar_codigos
from collections import Counter

def processar_virus(nome, accession):
    dna = get_dna_sequence(accession)
    if not dna: return

    codons = [dna[i:i+3] for i in range(0, len(dna) - 2, 3)]
    frequencias = Counter(codons)
    
    raiz = Huffman(codons)
    tabela_codigos = gerar_codigos(raiz)
    
    total_bits_huffman = sum(frequencias[c] * len(tabela_codigos[c]) for c in frequencias)
    total_bits_original = len(dna) * 2 
    
    taxa = (1 - (total_bits_huffman / total_bits_original)) * 100

    print(f"Taxa de compressão: {taxa:.2f}%")
